# تست روی گوشی

۱. USB debugging را روشن کنید، اتصال کامپیوتر را تأیید کنید و فایل **debug-phone.cmd** را اجرا کنید.

یا در PowerShell داخل پوشهٔ پروژه:

```powershell
.\scripts\debug-phone.ps1
```

برای نصب بدون debugger:

```powershell
.\scripts\debug-phone.ps1 -InstallOnly
```

۲. در Welcome ابتدا مجوزهای Notification access، Display over other apps و Service notifications را یکی‌یکی فعال کنید؛ تا هر سه مجوز فعال نشوند وارد Home نمی‌شوید. Battery optimization اختیاری است. اگر Android گزینهٔ دسترسی را مسدود کرد، در App info منوی سه‌نقطه گزینهٔ Allow restricted settings را بررسی کنید.

۳. یک آهنگ در Spotify، YouTube Music یا پلیر خودتان پخش کنید. عنوان، خواننده، منبع و زمان پخش باید مطابق پلیر باشند. بدون انتشار اطلاعات از سوی پلیر، تشخیص تضمین نمی‌شود.

۴. Floating lyrics را روشن کنید، به برنامهٔ دیگری بروید، پنجره را با دستهٔ بالای آن بکشید، جمع و باز کنید.

۵. آهنگ را عوض کنید؛ pause/resume و جلو/عقب‌بردن زمان را امتحان کنید. اگر متن زمان‌دار موجود باشد، خط فعال باید جابه‌جا شود. در Settings با Sync adjustment تأخیر را اصلاح کنید.

۶. یک آهنگ با متن فارسی و یک آهنگ بدون متن زمان‌دار تست کنید. متن فارسی باید وزیرمتن و راست‌به‌چپ باشد؛ متن بدون sync باید کامل و قابل پیمایش بماند.

۷. برنامه را از Recent Apps حذف کنید. برای این تست ابتدا با کلید **d** از debugger جدا شوید. پنجره باید همچنان کار کند، مگر اینکه سیاست باتری سازنده پردازش را متوقف کند. Force stop تست دیگری است و طبیعتاً برنامه را متوقف می‌کند.

۸. تمام گزینه‌های ظاهر، حالت روشن/تیره، رنگ دستگاه، تغییر ابعاد، شفافیت و تغییر منبع API را امتحان کنید. کلید Musixmatch اختیاری است؛ برای LRCLIB و Lyrics.ovh ثبت‌نام لازم نیست.

۹. اینترنت را قطع کنید؛ برای آهنگ cache‌شده متن باید همچنان قابل دریافت باشد. برای آهنگ جدید باید خطای روشن دریافت شود. بعد از اتصال، Refresh را بزنید.

۱۰. صفحه را خاموش و روشن کنید، گوشی را بچرخانید، مجوز overlay را موقتاً بردارید و دوباره بدهید. پنجره نباید خارج از صفحه گیر کند.

برای گزارش نتیجه بنویسید: مدل گوشی، نسخهٔ Android/رابط سازنده، نام پلیر، آهنگ و خواننده، منبع lyrics، مراحل بازتولید و نتیجهٔ مورد انتظار/واقعی. کلید API یا محتوای نوتیفیکیشن خصوصی را در گزارش نفرستید.
